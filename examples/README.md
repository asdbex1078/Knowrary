# 示例

`sample-vault/` 是一个**能直接用的最小知识库**：9 个节点、12 条边、一份摆好的图、一个学习项目。

它的用处是让人**第一次打开就有东西可点**——空库里什么都点不动，也就看不出这程序在干什么。

两种用法：

1. **铺进新库**：「设置 → 知识库 → 选择目录」挑一个空目录，勾上「放一份示例内容」。
   这是推荐做法——示例进了你自己的目录，怎么改都行，也不会和程序更新打架。
2. **直接切过去**：把当前库切成 `examples/sample-vault` 本身，立刻就能玩。
   **随便改**，和任何一个库一样：写节点、拖位置、答题、复习，都会落在这里。
   代价是它在程序仓库里，你改过之后 `git pull` 会冲突——**冲突不管**，
   真要保住你写的东西，`git stash` 或者复制一份出去。

## 里面有什么

题材是 **HTTP 的三代演进**：人人都懂，年份明确，而且天然覆盖了全部 5 个关系族——

| 关系族 | 示例 | 在哪 |
| --- | --- | --- |
| 结构 | `http-1-1 属于 http` | 三个版本都挂在 `http` 下 |
| 依赖 | `http-3 依赖 quic`、`quic 基于 udp` | 换掉传输层这条线 |
| 演化 | `http-1-1 演化为 http-2 (2015)` | 带年份，历史视图能按年回放 |
| 对照 | `tcp 对比 udp` | 可靠有序 vs 尽力而为 |
| 弱关联 | `http-2 相关 队头阻塞` | 指向一个还没写的点 |

还有一个 **stub**（`nodes/_stubs/head-of-line-blocking.md`）：被两个节点引用、但正文还没写。
它演示的是"先把边连上，别让『还没写』变成『想不起来要写』"——「今日」面板会把它排进来催你。

项目 `http-evolution` 把这 8 个点分成三个阶段，打开项目面板就能看到进度（7 个学过、1 个只有壳）。

## 不只有图

空着的面板等于不存在的功能，所以示例连**流水数据**一起造了（全是编的）：

| 数据 | 点亮哪一屏 |
| --- | --- |
| `.knowrary/review-log.json` | 「今日」有到期任务、画布上有金色圆点、日历有热力。四个节点摆出三种状态：学稳了（到期在将来）、今天刚好到期、忘过一次被打回去 |
| `.knowrary/quiz-log.json` | 错题本两条。其中 HTTP/2 那题**自评是「模糊」却答漏了两点**——演示「错题本压过自评」：你说记得，答漏了照样红 |
| `素材/HTTP3-为什么非要换掉TCP.md` | 「导入」面板里能选到的真文章。拆出来的点会和图里的 `quic` / `tcp` / `http-2` 自动认亲，认不出的落 stub。**这是最值得试的一条** |

**日期不会烂**：示例记着一个锚点日期（`.knowrary/_demo.json`），铺进新库时按「今天 − 锚点」
把复习与答题的日期整体平移，所以无论哪天初始化，看到的都是"昨天刚学过、今天有一个到期"，
而不是"逾期 183 天"。那个锚点文件铺完就删，不会留在你的库里。
