# TCP

面向连接的传输协议：三次握手建连，之后是一条**可靠、有序的字节流**。
丢包重传、乱序重排、流量控制、拥塞控制，全部由内核替你做完。

## 核心内容

"有序"是它最大的优点，也是它在多路复用场景下最大的包袱——
上层就算把数据分成了互不相干的几路，TCP 也只认一条字节流，**前面的字节没到，后面的就不交付**。
[[http-2]] 栽的就是这个跟头。
