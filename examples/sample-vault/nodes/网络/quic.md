# QUIC

在 UDP 之上、用户态实现的传输协议。RFC 9000（2021）。

## 核心内容

它把三件事收进了一层：
1. **流**——一条连接里有多条独立的流，丢包只卡住它自己那条，这是对 [[head-of-line-blocking]] 的真正回答；
2. **加密**——TLS 1.3 和握手合并，常见情况 1-RTT 建连，回访 0-RTT；
3. **连接迁移**——连接由连接 ID 标识而不是 IP 四元组，从 Wi-Fi 切到蜂窝网不断线。

代价：跑在用户态，CPU 开销比内核 TCP 高；而且部分网络会拦 UDP。
