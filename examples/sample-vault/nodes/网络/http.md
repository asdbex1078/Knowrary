# HTTP

一问一答的应用层协议：客户端发一个请求（方法 + URL + 头部 + 可选正文），服务端回一个响应
（状态码 + 头部 + 可选正文）。**它是无状态的**——两次请求之间服务端不欠你任何记忆，
Cookie、Session 都是后来在这个前提上补的。

## 核心内容

值得记住的是这条分界：**语义**（方法、状态码、头部这些"说什么"）几乎没变过，
三十年里翻来覆去改的是**传输**（"怎么送"）——连接怎么复用、帧怎么切、跑在哪个传输层上。
HTTP/2 和 HTTP/3 都没有发明新的方法或状态码。

看懂这条分界，三个版本的差别就不用死记了。

## 线头
- 语义那一半后来被单独抽成了 RFC 9110，值得顺一遍
