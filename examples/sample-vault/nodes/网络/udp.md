# UDP

无连接的数据报协议：给一个目的地址，把包扔出去，**不保证到达、不保证顺序、不重传**。

## 核心内容

它的价值不在"快"，而在**不挡路**。TCP 的重传和有序交付写死在内核里，想改要动操作系统；
UDP 什么都不做，于是 [[quic]] 可以在用户态把连接、重传、多路复用重新实现一遍，
而且随应用一起升级——不用等全世界的内核更新。
