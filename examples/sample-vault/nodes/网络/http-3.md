# HTTP/3

语义还是那个 HTTP，但底下换成了 [[quic]]——一个跑在 UDP 上的传输协议。

## 核心内容

关键变化：**多路复用下沉到了传输层**。QUIC 自己认识"流"这个概念，丢一个包只影响它所属的那条流，
其余流照跑。加上握手和 TLS 合并（0-RTT / 1-RTT）、连接迁移（换 Wi-Fi 不断线），
这些都是 TCP 那一层给不了的。

代价是它跑在 UDP 上，而不少企业网络和中间设备对 UDP 不友好，所以实践中要能回落到 HTTP/2。

## 关系
- 属于:: [[http]]
- 依赖:: [[quic]] — 多路复用下沉到传输层，这是它区别于 HTTP/2 的全部理由
