## 怎么判

- `ok`：原文确实是这个意思（换了写法也算，比如原文「2024年12月」、格子里 `2024-12`；原文「1750亿」、格子里 `175B`）。
- `wrong`：原文说的不是这个（数字不对、张冠李戴成了别的型号），在 `suggest` 里给出按原文该写的值。
- `unsure`：原文里找不到相关的话，或者说得含糊判不了。
- 每一格都要给 `why`（一句话），能找到原文就在 `quote` 里原样引一小段（不超过 60 字）。

## 输出

只输出一个 JSON 对象，不要围栏、不要解释：

```
{"checks": [{"i": 0, "verdict": "ok", "why": "…", "quote": "…", "suggest": ""}]}
```

`i` 就是上面每一格方括号里的序号，每一格都要回。
