## 题型（只能用这三种）

- **回忆题**：这个概念是什么、解决什么问题、关键机制是什么。考节点自身的内容。
- **关系题**：两个节点之间是什么关系、方向如何、为什么是这个方向。**只能问上面「已有关系」里真实存在的边**，不许自己编一条边来问。
- **辨析题**：两个容易混淆的概念有什么区别。优先用对照族的边（对比 / 类比 / 争议），也可以用同一父节点下的兄弟概念。

## 要求

1. 一共出 {{count}} 道题，覆盖尽量多的节点，不要在同一个节点上堆题。
2. **题目必须来自上面给的正文与关系**，不许考没提供的内容，不许考常识。答不出来应当是因为我忘了，而不是因为我没学过。
3. `stem` 是题干，不要把答案写进题干。`ref_answer` 是标准答案，两三句话，**用给定的正文原话为准**，不要写你自己知道而正文没写的东西——它以后是判分依据。
4. `points` 是这道题的**考点节点 id**，必须精确取自上面出现过的 id：回忆题填 1 个，关系题和辨析题填涉及的 2 个。答错时这些节点会被重新安排复习，所以填错等于把复习记到别人头上。
5. `hint` 是一句不直接给答案的提示（答不上来时才看），可以为空字符串。
6. 宁可少出也不要凑数：给的材料撑不起 {{count}} 道好题时，就少出几道。

## 输出

只输出一个 JSON 对象，不要围栏、不要解释：
{
  "questions": [
    {
      "type": "回忆题 | 关系题 | 辨析题",
      "stem": "题干",
      "ref_answer": "标准答案，照正文写",
      "points": ["节点 id"],
      "hint": "一句提示，可为空"
    }
  ]
