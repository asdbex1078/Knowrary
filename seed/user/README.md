# ~/.knowrary —— 你的配置

这个目录是**跟人走的**那一半，和知识库分开：

| 文件 | 是什么 |
| --- | --- |
| `config.json` | 当前用哪个知识库、最近用过哪些（设置 → 知识库 里改） |
| `llm.local.json` | 模型与密钥（设置 → 模型 里改；模板见 `llm.example.json`）。**所有知识库共用** |
| `settings.json` | 复习与出题的几个开关（设置 → 学习与复习） |

**知识库里只有数据**：节点、领域总览、图的摆位、项目清单、复习记录、关系类型表。
所以换一个库——你自己的、别人的参考库、示例库——模型、开关、侧写都不用重来一遍，
参考库里也不会躺着别人的密钥和自我介绍。

**教练侧写是例外，它跟库走**：`<库>/.knowrary/coach.md`（模板 `coach.example.md`）。
一个库一份、互不覆盖——切到别人的参考库，该读到那个库的口气，而不是把自己那份盖上去；
项目级 `coaches/<项目 id>.md` 本来就在库里，两者放一起才一致。默认都不入库。
