# NLP

## 描述

让机器处理人类语言这条任务线。

## 核心内容

三个阶段，每次换的都是**知识从哪来**：

1. **规则**（1954–1990s）：语言学家手写文法。撞的墙和 [[知识获取瓶颈]] 是同一堵。
2. **统计**（1990s–2012）：从语料里数频率。n-gram、HMM。
3. **神经**（2013–）：[[word2vec]] 把词变成向量，[[注意力机制]] 解决长依赖，[[Transformer]] 把它做成纯注意力架构。

**这条线的特殊之处：Transformer 出生在这里，然后去统一了 [[CV]] 和 [[ASR]]。**
