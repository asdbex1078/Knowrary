# x86

## 描述

1978 年 Intel 8086 定下的指令集，是 [[CISC]] 路线最成功的落地。

## 核心内容

- **向后兼容是它的护城河也是它的包袱**：1978 年的二进制今天还能跑，代价是指令编码长度可变（1～15 字节）、译码器极其复杂。
- **外壳 CISC、内核 RISC**：从 P6（1995）起，复杂指令在前端被拆成定长的 μops，后端是乱序执行的 RISC 式流水线——见 [[现代Intel微架构]]。
  所以「x86 是 CISC」这句话今天只对前端成立。
- **授权封闭**：只有 Intel 和 AMD 能造，这一条是它和 [[ARM]] 生态差异的根源。
