# ARM

## 描述

1985 年 Acorn Computers 推出的精简指令集，属于 [[RISC]] 路线。

## 核心内容

- **低功耗不是附带属性，是设计目标**：定长指令、译码简单、晶体管少，这一条直接决定了它在电池供电场景的统治地位。
- **卖 IP 不卖芯片**：ARM 公司授权设计，苹果 / 高通 / 三星各自实现。这个商业模式和 [[x86]] 的封闭授权是同一件事的两面，也是生态分叉的原因。
- **反攻高端**：Apple Silicon（2020）和服务器端的 Graviton 证明了「RISC 只适合低功耗」是个过时的结论。
