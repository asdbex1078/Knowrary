# RISC-V

## 描述

2010 年由加州大学伯克利分校发起的开放指令集，属于 [[RISC]] 路线。

## 核心内容

- **开放是它唯一的、也是决定性的差异**：任何人可以实现、扩展、卖，不付授权费。[[x86]] 封闭、[[ARM]] 收费，它免费——**这是商业模式的差异，不是技术的差异**。
- **模块化**：一个极小的基础整数指令集（RV32I，47 条），乘除 / 浮点 / 向量都是可选扩展。嵌入式只实现基础集，服务器再叠。
- **设计上吸取了 [[MIPS]] 的教训**：比如取消延迟槽。
