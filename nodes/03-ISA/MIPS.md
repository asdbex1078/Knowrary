# MIPS

## 描述

1985 年由斯坦福 John Hennessy 团队设计的精简指令集，属于 [[RISC]] 路线。

## 核心内容

- **它是「五级流水线」这个心智模型的来源**：取指 / 译码 / 执行 / 访存 / 写回，几乎所有体系结构教材讲流水线都用它。
- **设计上的极简**：定长 32 位指令、三操作数、load-store 架构——没有历史包袱，所以适合讲清楚 RISC 的道理。
- **商业上输了**：嵌入式市场被 [[ARM]] 拿走，但它的设计思想直接影响了 [[RISC-V]]。
