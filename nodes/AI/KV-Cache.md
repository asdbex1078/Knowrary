# KV-Cache

## 描述
自回归解码复用历史 K/V，把每步重算换成常驻显存——MQA/GQA/MLA 三条路线的共同改造对象

> **年份锚点：2017。** 它不是某篇论文提出的，是 Transformer 自回归解码的实现产物——每步只算新 token 的 Q，
> 历史 K/V 直接复用，随架构一起出现。锚 2017 是为了让它在历史视图上和 Transformer 同侧、排在 MQA（2019）之前。
>
> （`year` 取「历史视图锚点年」口径，不是唯一发明年。）
