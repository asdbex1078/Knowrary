# 混合精度与量化

## 描述
FP32→FP16/BF16→INT8/FP8 是硬件与算法共同演进的产物，解释 Tensor Core 为何出现，也是端侧部署的前提

## 关系
- 支撑:: [[NPU]] — 端侧 NPU 只做定点低精度算子，INT8/FP8 量化是它能落地推理的前提
- 影响:: [[GPU]] — FP16/BF16 混合精度训练的需求直接催生了 Tensor Core 这类低精度矩阵单元进入 GPU
- 影响:: [[内存墙]] — 量化把权重和 KV 的字节数砍下来，与 MQA/GQA/MLA 一样是打访存瓶颈的手段，内存墙节点 desc 已点名量化
- 影响:: [[KV-Cache]] — KV-Cache 量化（INT8/FP8 存 K/V）是压缓存显存的常见路线，与注意力头共享路线互补
- 相关:: [[TPU]] — TPU v1 以 INT8 定点推理、后代引入 BF16 训练，是低精度数值格式与专用芯片协同演进的实例
