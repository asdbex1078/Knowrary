# JIT

JIT（时编译器 / Just-In-Time）。实现了编译原理的前端和后端，只不过在内存中动态的对语言进行编译。
- 优点：执行速度快（对源代码进行了高度优化）
- 缺点：启动速度慢，因为需要花费大量的时间进行编译优化

与 [[解释器]] 循环配合（解释执行 ⇄ 热点编译）。Graal Compiler 是用 Java 写的 JIT。

> **年份锚点：1983。** Deutsch & Schiffman 在 Smalltalk-80 上做的动态翻译，公认的第一个现代意义 JIT
> （解释执行 + 热点编译 + 内联缓存）。其他说法：思想可追到 1960 年代的 LISP；工业普及的里程碑是
> HotSpot（1999）。
>
> （`year` 取「历史视图锚点年」口径，不是唯一发明年。）
