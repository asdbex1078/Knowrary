# OS

操作系统。图中作为 JVM 的运行基座，以及 eBPF 所在的内核层（系统调用协议 int 0x80 / sysenter）。未展开——待补。

> **年份锚点：1969（UNIX）。** 本节点在图上的角色是「JVM 的运行基座」和「eBPF 所在的内核层」，
