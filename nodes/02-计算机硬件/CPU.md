# CPU

组成：[[控制器]]、[[运算器]]、[[高速缓存]]、[[寄存器]]；具体实例 [[Intel平台]]。

### 执行流程（cpu 内部）
1. 通过 [[ISA]] 控制"控制单元"（CU）
2. 控制单元操作存储单元（MU）从缓存里获取数据
3. 将数据从存储单元放到运算单元（AU）
4. 将运算结果放回存储单元

缓存 ⇄ 主存交换数据；寄存器单元用来存储缓存中的数据。
