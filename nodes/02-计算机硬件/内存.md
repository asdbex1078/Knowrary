# 内存

主存 / 内存 / RAM。分类：[[RAM]]、[[ROM]]、[[EPROM]]。

CPU 通过 [[总线]] 与内存交互：控制读写 / 控制地址 / 读写数据。
指令与数据如何放进内存 → [[程序的内存布局]]；地址编号 → [[内存地址]]。

## 关系
- 包含:: [[RAM]] — 内存分类：RAM / ROM / EPROM
- 包含:: [[ROM]] — 内存分类：RAM / ROM / EPROM
- 部件:: [[内存地址]] — 用 16 进制给每个字节编号，一个地址对应 1 字节
